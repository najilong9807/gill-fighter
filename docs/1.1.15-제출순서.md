## 상점 정리 (10/22 오전, 종한 요청)
- **배치**: 꾸미기 · 배경은 '내 것 → 할로윈(겨울) 한정 → 진주로 사요(싼 것부터) → 💎 보석 전용(싼 것부터)', 칸마다 작은 제목과 개수. 전엔 시즌 · 보석 전용 · 진주 상품이 추가된 순서대로 섞여 있었음
- 부스터: '한 개씩 / 부스터 세트', 보석: '무료 → 보석 묶음 → 부스터 꾸러미 → 편리한 상품 → 진주로 바꾸기'
- **아이콘**: 꾸러미 · 세트는 선물 상자(×개수), 진주 교환은 진주 더미(많을수록 더 많이 + 5.3K 같은 표시), 하루권은 시계, 에너지 통은 배터리, 보석은 보석 모양. 부스터 '진주 1.5배' 아이콘이 ×2로 나오던 것 → ×1.5
- 꾸미기 아이콘 자동 맞춤: 헤드폰 · 귀마개 · 혀 · 땀방울 같은 작은 건 칸에 맞게 키우고, 꼬리 · 오라 효과는 여러 순간을 겹쳐 진하게 + 가운데로(오라가 오른쪽에 잘리던 것 해결)
