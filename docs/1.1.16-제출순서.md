# 1.1.16 (준비 중 · 10/23)

1.1.15 배포 후 종한 요청 2가지, 작은 정리 업데이트.

## 바뀐 것
1. **랭킹 칭호 정리**: 1~3위 메달 🥇🥈🥉와 '나' 표시는 그대로, 칭호는 1위 👑 바다의 왕만 남김(은빛 지느러미 · 구릿빛 지느러미 · 상위 10 뺌)
2. **'알림' 칸 따로**: 설정의 알림 받기 스위치가 '성능' 안에 묻혀 있어 찾기 어려웠음 → 소리 바로 아래 '알림' 칸(영 Notifications · 일 通知). 순서: 프로필 · 화면 표시 · 소리 · 알림 · 성능 · 업데이트 소식 …
   - 영어 이름 'Turn on' → 'Get notifications'(첫 알림 묻는 창 버튼도 같은 말)
3. **🔔 알림 내역 (10/23 오후, 종한 요청)**: 홈 오른쪽 위 첫 버튼(알림 · 미션 · 랭킹 · 설정). 화면에 뜬 알림을 최근 30개까지 기기에 저장(게임 중 알림 제외, 같은 제목 10분 안이면 하나로) → 누르면 제목 · 설명 · '3시간 전' 목록, '모두 지우기'. 빨간 점은 안 띄움(이미 화면에서 본 알림이라)
4. **'환경 설정' 꼬리표 뺌**: 설정 화면 위 민트색 꼬리표가 보라색 제목 '설정'과 겹쳐 있었음. 다른 화면도 확인 — 도감 '모은 물고기 2/89', 결과 '이번 판 결과'는 제목과 다른 정보라 그대로
5. **설정 탭**: 일반(프로필 · 조작 · 언어 · 알림) / 그래픽(화면 표시 · 성능) / 사운드 / 저장(백업 · 계정 · 초기화) / 정보(업데이트 소식 · 도움말 · 문의). 영 General/Graphics/Sound/Data/Info, 일 一般/画面/サウンド/データ/情報. 설정 열 때마다 '일반'부터, 탭 줄은 스크롤해도 위에 붙어 있음. 320~430 폭 · 가로에서 글자 잘림 0
6. **시작하자마자 먹히는 판 줄이기 (10/23 오후, 종한 선택)**: 근거 — 7~8번째 판에서 3~6초 만에 끝나는 기록 반복
   - 싱글(기록 도전 · 심해 탐험) 시작 6초 동안 나보다 큰 물고기는 새로 안 생김(먹이 크기로), 시작 때 화면 안팎 가까이 있던 큰 물고기는 화면 밖으로 밀어 둠. 생존 · 대전 · 친구 바다는 그대로
   - 결과 화면 맨 위 빨간 글씨 '○○에게 먹혔어요.' + 20초 안에 끝난 판은 요령 한 줄(빨간 테두리 / 특수능력 / 작은 것부터 돌아가며)
7. **처음 켠 사람은 바로 헤엄치기 (종한 선택)**: 근거 — 신규 9명 중 3명이 켜고 한 판도 안 함, 1.1.15 첫 영어 유저는 닉네임 창에서 54초
   - 처음 켜면 닉네임 창 없이 바로 연습 바다(추천 이름이 미리 붙음), 닉네임 창은 첫 판 뒤 홈에서 한 번(다른 창이 떠 있으면 닫힌 뒤). 버튼 '이 이름으로 정하기'
   - 기존 사람 중 닉네임 안 정한 사람에겐 안 뜸(새로 시작한 사람만)
8. 업데이트 소식: '작은 정리 업데이트 🐠' + 시작 편하게 · 알림 버튼 · 설정 탭 · 랭킹 네 줄(한영일)
