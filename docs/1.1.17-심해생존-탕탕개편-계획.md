# 1.1.17 심해 생존 대개편 계획 — 탕탕특공대 방식 (10/24 종한 요청)

종한 선택: 장비 등급 · 각성 짝 보이기 · 챕터 늘리기 · 보급 상자/이벤트 웨이브 **전부**, 가장 원하는 손맛은 **"스킬 조합해서 화면 쓸어버리기"**.

## 지금 심해 생존에 이미 있는 것 (탕탕 기본 틀)
- 자동 공격, 레벨업 3택 + 다시 뽑기, 무기 24종 · 능력 11종(무기 6단계 · 능력 5단계)
- 각성 24종: 무기 6단계 + 짝 능력 1단계 이상 → 다음 레벨업 때 각성. 레벨업 카드에 '각성: 6단계 + 「능력」' 힌트, 기록실에 각성 도감
- 장비 4칸(송곳니 · 갑옷 · 부적 · 지느러미) 20종, 등급 4단(일반 · 희귀 · 영웅 · 전설, 색 있음), 같은 장비 합쳐 등급 올리기
- 짝꿍, 생존 훈련(영구 강화), 탐사선(순찰 보상), 잠수 등급, 일일 임무, 주간, 업적
- 챕터 8개(10분 + 시간 상자 3개), 무한 모드, 보스 러시

## 탕탕과의 차이 = 이번에 채울 것

### ① 화면 쓸어버리기 (핵심 손맛)
- **각성 순간 연출**: 화면 번쩍 + 0.4초 슬로모션 + 각성 무기 첫 발은 범위 2배로 주변 싹쓸이, 강한 햅틱
- **각성 2개 연계기**: 각성 무기 2개를 가지면 8초마다 둘을 섞은 '연계 공격'이 화면 전체에 한 번(예: 고압 물대포 + 복어 불꽃놀이 = 화면을 가로지르는 불꽃 물줄기). 연계 조합 표를 기록실에 추가
- **쓸어버릴 대상**: 각성 뒤 30초마다 '물고기 떼 러시'(작고 약한 적이 화면 가득 몰려옴) → 쓸어버리는 장면이 자주 나오게
- 처치 수 팝업 '×128 한 번에!' (한 번에 50마리 넘게 잡으면)

### ② 각성 짝 보이기
- 화면 위 작은 **각성 진행판**: 가진 무기 아이콘 옆에 짝 능력 아이콘(없으면 회색, 있으면 빛남), 6단계 + 짝 있음 = 금색으로 '다음 레벨업 각성!'
- 레벨업 카드: 이 카드를 고르면 각성이 완성되는 경우 금색 테두리 + '각성 완성' 띠
- 일시정지 화면에 각성 짝 전체 표(가진 것 위주)

### ③ 장비 등급 (탕탕식 파밍)
- 등급 4단 → **6단**: 일반 · 고급 · 희귀 · 영웅 · 전설 · 신화(새로 고급 · 신화)
- **전설 고유 효과**: 장비 20종마다 전설이 되면 붙는 특수 효과 1줄(예: 상어 이빨 전설 = 치명타가 작은 폭발)
- 상자 열기 연출: 등급 색 빛기둥, 전설 이상은 화면 흔들림 + 햅틱
- 합성 화면에 '다음 등급에서 생기는 것' 미리 보기

### ④ 챕터 늘리기
- 8개 → **20개**: 지금 있는 바다 배경 · 적 · 보스를 새 조합으로 + 챕터별 규칙 하나(빠른 적 · 어둠 · 해류 · 독 장판 · 엘리트 많음 등)
- 9~20장은 앞 챕터를 깨야 열림, 시간 상자 보상은 장마다 조금씩 커짐

### ⑤ 보급 상자 · 이벤트 웨이브
- **보급 상자**: 2분마다 위에서 낙하(그림자 표시) → 열면 자석 · 폭탄 · 하트 · 무작위 레벨업 1회 중 하나
- **이벤트 웨이브**(분 단위 일정, 화면 위 예고 3초): 포위 링(원형으로 둘러쌈) · 엘리트 러시 · 황금 떼(경험치 많이) · 물고기 떼 러시

## 추가 요청 (10/24 22시, 종한)
- '햅틱도 손맛이 없고 쾌감도 없다' → 연속 처치할수록 햅틱이 약 → 중 → 강으로 세짐, 많이 쓸면 잠깐 멈춤(히트스톱) · 화면 흔들림 · '×N 한 번에!'
- '물고기도 좀 큰 애들로' → 보스 뺀 적 크기 1.25배

## 진행 상황
- ✅ 1단계(10/24 밤, 개발본 · 아직 빌드 안 함): 적 1.25배 · 연속 처치 햅틱 세기 · 히트스톱 · '×N 한 번에!' · 각성 순간 연출(번쩍 + 슬로모션 + 화면 싹쓸이 + 강한 햅틱) · 각성 2개 연계 공격(8초마다 화면 전체) · 첫 각성 12초 뒤부터 35초마다 물고기 떼 러시 · 화면 왼쪽 각성 진행판 · 레벨업 카드 '각성 완성' 금테
  - 시험: 연속 처치 햅틱 LIGHT → MEDIUM → HEAVY 확인, 각성 연출 · 연계 · 러시 동작, 회귀 18개 통과, 프레임 부담 1.1.16과 비슷(무기 각성 4개 + 적 150마리 스트레스)
  - 1.1.16은 따로(저장소 본) — 1.1.16 제출 뒤에 1.1.17로 합침

## 진행 순서 (빌드 1번당 한 덩어리씩, 매번 회귀 · 화면 점검)
1. ① 화면 쓸어버리기 + ② 각성 짝 보이기 — 가장 원하는 손맛부터
2. ⑤ 보급 상자 · 이벤트 웨이브

- 성능: 화면 가득 적 + 연출 → 가벼운 모드 · 느린 폰에서 프레임 시뮬 확인
