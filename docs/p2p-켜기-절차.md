# 대전 P2P(폰끼리 직접 연결) 켜기 절차

지금 상태: **꺼져 있음.** 앱(1.1.14 이상)에는 기능이 들어 있지만, 원격 설정 `gf_cfg`에 `p2p` 값이 없어서 지금 방식(실시간 서버 중계)으로만 돕니다.

## 1단계 — 소개소 함수 깔기 (한 번만)
- 파일: `sql/gf_p2p.sql`
- 방법 A: Claude가 Supabase 연결로 적용 → 승인 창이 뜨면 **허용** 눌러 주세요. (지금까지 두 번 취소됨)
- 방법 B: Supabase 대시보드 → SQL Editor → 파일 내용 붙여 넣고 Run
- 확인: `select public.gf_p2p('t','test',  '[]'::jsonb, 0, 16, true);` 가 오류 없이 json을 돌려주면 OK
- 이 단계만으로는 아무것도 바뀌지 않음(앱이 아직 안 씀)

## 2단계 — 실제 폰 2대로 시험
1. 폰 두 대에 같은 버전(1.1.14 이상) 설치, 둘 다 **친구** 메뉴에서 같은 4자리 번호 입력(따로 떨어진 바다라 다른 사람에게 영향 없음)
2. 대시보드에서 잠깐 켜기 (아래 켜기 명령)
3. 확인할 것
   - 서로의 물고기가 끊김 없이 보이는지 (와이파이 ↔ LTE 조합도 1번)
   - 물기 · 죽음 · 1등 끝내기가 양쪽에 똑같이 보이는지
   - 한 폰을 비행기 모드 → 상대 화면에서 15초쯤 안에 사라지는지
   - 같은 바다에 컴퓨터 물고기가 자연스럽게 채워지는지
4. 이상하면 바로 끄기 명령 → 앱은 다음 접속부터 원래 방식

## 켜기 / 끄기 명령 (대시보드 SQL Editor)
- 켜기: `update gf_cfg set v = v || '{"p2p":1}', updated_at = now() where k='arena';`
- 끄기: `update gf_cfg set v = v - 'p2p', updated_at = now() where k='arena';`
- 현재 값 보기: `select v from gf_cfg where k='arena';`
- 앱은 켤 때 한 번 읽으므로, 바꾼 뒤에는 앱을 완전히 껐다 켜야 반영

## 켜면 좋아지는 것
- 위치 주고받기가 실시간 서버를 거치지 않아 서버 메시지 한도 · 동시 접속 한도 걱정이 줄어듦 (무료 요금제 유지)
- 직접 연결이 안 되는 상대(일부 회사 · 학교 와이파이)는 안 보이고, 대신 컴퓨터 물고기가 채워짐

## 정리
- 오래된 기록은 함수가 알아서 지움(30초 지난 멤버 · 1분 지난 메시지)
- 문제 생기면 끄기 명령 한 줄이면 앱 업데이트 없이 원래대로
